# DGUS 320x480 migration draft

Generated from the legacy 240x320 package by `tools/migrate_dgus_320x480.py`.
The BMP backgrounds are geometric drafts only; do not release them without UI/UX review.
Use `VP_map_320x480.csv` and `layout_320x480.json` to rebuild the final DGUS project in DGUS Designer.
The legacy binary `RMP_HMI/archive/legacy-240x320/DWIN_SET` is intentionally not overwritten.
