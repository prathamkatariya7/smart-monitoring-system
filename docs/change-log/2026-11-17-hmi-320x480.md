# 2026-11-17 — DWIN 320×480 HMI upgrade

The firmware target was updated for the DWIN DMG48320C035_03WN portrait panel at 320×480. Four tactile buttons now follow the global UP, DOWN, SELECT and MODE contract with debounce, hold-repeat, safe back navigation and atomic firmware-owned focus/diagnostics registers.

A reproducible migration tool generated draft 320×480 backgrounds, layout metadata and a scaled VP map. The old 240×320 source package and binary export were retained under `RMP_HMI/archive/legacy-240x320/` for traceability and are no longer active release instructions.

The draft package requires UI/UX review, DGUS export and exact-panel bench validation before a regulated release.
